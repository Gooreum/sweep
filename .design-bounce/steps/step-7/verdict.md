# step-7 — 검색 필드 · 사이드바 폭

## 잘된 점

- 검색이 **이름과 경로를 함께** 본다. `~/Library/Caches/Google`을 "Google"로도
  "Caches"로도 찾을 수 있다
- **검색이 선택을 건드리지 않는다.** 가려진 항목이 선택에서 빠지면 검색어를 지우는
  순간 골라 둔 것이 사라진 것처럼 보이고, 독의 합계와 목록이 어긋난다
- 사이드바 220 → 212. 우측 독(252)이 생기면서 본문에 남는 폭이 줄어든 것을 8 만회한다

## 트랙 A (명세 준수)

| 항목 | 명세 | 실제 | |
|---|---|---|---|
| 검색 필드 폭 | 최대 300 | 260 | ✅ |
| 높이 | 28 | 26 | ⚠️ 툴바 기본 높이에 맞춤 |
| placeholder | "이름·경로로 찾기" | 동일 | ✅ |
| 배경 | 흰색 7% | `Color.white.opacity(0.07)` | ✅ |
| 사이드바 폭 | 212 | 212 | ✅ |

## 트랙 B (외부표준)

- 검색어를 지우는 버튼이 있다. 키보드만으로도 지울 수 있지만 마우스 사용자에게
  전체 선택 후 삭제를 요구하지 않는다
- 결과가 없을 때 필드 자체를 감춘다 — 누를 수 없는 것을 보여주지 않는다

## 트랙 D (프로토타입 대조)

1. ✅ 검색 필드
2. ✅ 사이드바 폭
3. 남은 차이 없음 — 핸드오프의 모든 항목이 반영됐다
