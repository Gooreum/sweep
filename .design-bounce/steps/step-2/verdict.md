# step-2 — 섹션 헤더 · 상단 설명 줄

## 잘된 점

- 섹션 헤더가 caret + 작은 라벨 + 개수 + 합계로 정돈됐다. 본문보다 작아 목록이 헤더에 눌리지 않는다
- 헤더 어디를 눌러도 접힌다. 접힘 상태는 `ScanModel`이 소유해 탭을 옮겨도 살아남는다
- 상단 한 문장이 "무엇을 기준으로 고르라는 것인가"를 말한다 — 목록만 던지던 것과 다르다
- 독 버튼이 패널 폭을 채운다 (이전 캡처에서 오른쪽으로 치우쳐 있었다)

## 트랙 A (명세 준수)

| 항목 | 명세 | 실제 | |
|---|---|---|---|
| 섹션 헤더 높이 | 34 | `Theme.sectionHeaderHeight` | ✅ |
| 헤더 배경 | 재질/가라앉은 면 | `surfaceSunken` | ✅ |
| 라벨 | caption semibold, 자간 0.4 | 동일 | ✅ |
| 접기/펼치기 | 클릭 | `toggleCollapsed` | ✅ |
| 상단 설명 | 기능별 한 문장 | `Feature.reviewHint` | ✅ |

## 트랙 B (외부표준)

- 헤더 글씨 `textSecondary` / `surfaceSunken` — 기존 실측 통과 조합
- 합계·개수는 `textTertiary`. `surfaceSunken` 위 5.46:1 ✅
- caret 9pt는 장식이고 클릭 영역은 헤더 전체(높이 34)라 조작에 지장 없다
