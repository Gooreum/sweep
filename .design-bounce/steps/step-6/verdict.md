# step-6 — 툴바 통합 · 막대 치수 정리

## 잘된 점

- 전역 액션이 타이틀바로 올라갔다. 별도 툴바 줄을 만들면 사이드바 위에 가로줄이
  하나 더 생겨 본문이 그만큼 낮아진다 — 타이틀바는 어차피 비어 있었다
- `안전 항목 선택`이 메뉴 안에 접혀 있던 것을 버튼으로 꺼냈다. 가장 흔한 조작이
  두 번 눌러야 했다
- 막대의 `Capsule`을 `RoundedRectangle(4/3)`로 바꿨다. 높이 8·6에서 캡슐은 양 끝이
  과하게 둥글어 알약처럼 보였고, 창 안의 다른 막대와 모양이 달랐다

## 트랙 A (명세 준수)

| 항목 | 명세 | 실제 | |
|---|---|---|---|
| 툴바 통합 | 타이틀바로 | `.toolbar` | ✅ |
| 화면 제목 | 좌측 | `.navigation` placement | ✅ |
| 안전 항목 선택 · 다시 검색 | 우측 | `.primaryAction` | ✅ |
| 메뉴바 막대 radius | 4 | 4 | ✅ |
| 디스크 맵 막대 | 6pt | 6 | ✅ |
| 검색 필드 | 최대 300 | **없음** | ⚠️ |

> 검색 필드는 넣지 않았다. `ScanModel`에 필터가 없어 지금 올리면 **껍데기**가 된다.
> 명세에도 필터 동작 규칙이 없다 — 별도 기능으로 다뤄야 한다.

## 트랙 B (외부표준)

- 툴바 버튼은 시스템 기본 스타일이라 대비·포커스 링을 시스템이 보장한다
- 비활성 조건(`canScan`, 항목 0개)이 붙어 있어 누를 수 없는 버튼이 눌리지 않는다

## 트랙 D (프로토타입 대조)

1. ✅ 툴바 통합
2. `[Medium-Priority]` 검색 필드 없음 (근거 위)
3. `[Medium-Priority]` 사이드바 폭 220 (명세 212) — 8pt 차이로 눈에 띄지 않는다
