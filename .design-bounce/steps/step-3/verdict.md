# step-3 — 개요 히어로를 스택 막대로

## 잘된 점

- 도넛이 막대로 바뀌어 **가장 작은 조각이 읽힌다.** 중복 104.9MB는 전체의 1.5%인데
  링에서는 실처럼 사라졌다. 막대에서는 최소 폭 2% 하한 덕에 색 블록으로 보인다
- 범례가 색과 이름을 잇는다. 도넛일 때는 조각 위에 이름을 못 얹어 색만 떠 있었다
- 스캔 **전**에는 도넛을 그대로 쓴다 — 조각이 둘(사용/사용가능)이라 링이 제 몫을 한다

## 트랙 A (명세 준수)

| 항목 | 명세 | 실제 | |
|---|---|---|---|
| 막대 높이 | 8 | 8 | ✅ |
| 조각 간격 | 2 | 2 | ✅ |
| 범례 사각 | 7pt | 7 | ✅ |
| 합계 서체 | display(32) | `displayMono` | ✅ |
| 우측 항목 수 | "N개 항목" | 동일 | ✅ |

## 트랙 B (외부표준)

- 막대 색은 `Feature.tintHex` 기존 값 — 대비 검증을 이미 통과한 조합
- 범례 글씨 `textSecondary` / `surfaceRaised` ✅
- 조각이 색만으로 구분되지만 **범례가 이름을 붙여** 색각 이상에서도 읽힌다

## 트랙 D (프로토타입 대조)

1. ✅ 스택 막대 + 범례
2. `[Medium-Priority]` 기능 목록 행에 색 점 대신 SF Symbol 아이콘을 쓴다 —
   프로토타입은 8pt 색 점. 아이콘 쪽이 정보량이 많아 유지한다
3. `[Medium-Priority]` 하단 "되돌릴 수 없는 항목 N개는…" 주석이 아직 없다
