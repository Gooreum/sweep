# Sweep 한국어 용어집

같은 대상을 아래 말로 통일해요. 실제 경로와 제품 이름은 번역하거나 고치지 않아요.

| 대상 | 쓰는 말 | 이유와 쓰임 |
|---|---|---|
| 전체 정리 후보 찾기 | 한번에 찾기 | 스마트 스캔 대신 무엇을 할 수 있는지 말해요. 기존 사이드바 이름보다 짧아요. |
| 정크 파일 기능 | 정리할 파일 | 정크라는 말을 몰라도 이해할 수 있어요. 기존 길이를 유지해요. 실제로 불필요한지는 사용자가 골라요. |
| 큰 파일 기능 | 큰 파일 | 크기를 기준으로 찾는 기능임이 분명해요. 유지해요. |
| 중복 파일 기능 | 중복 파일 | 내용이 같은 파일을 뜻해요. 유지해요. 설명에서는 여분과 남는 원본을 구분해요. |
| 휴지통 기능 | 휴지통 | macOS에서 쓰는 이름이에요. 유지해요. |
| 디스크 맵 기능 | 공간 보기 | 폴더가 차지하는 공간을 살펴보는 행동을 말해요. 기존보다 짧아요. |
| CPU 기능 | CPU | 확인 대상의 이름을 유지해요. 설명에서는 컴퓨터를 바쁘게 하는 프로그램이라고 말해요. |
| 캐시 | 임시 파일 | 필요할 때 다시 생기는 파일이에요. 재생성 조건은 해당 설명에 남겨요. |
| 개발 관련 파일 전체 | 개발용 파일 | ‘앱 시험 도구’ 같은 직역어를 쓰지 않아요. 좁은 분류 이름은 ‘개발용 파일’이에요. |
| Xcode 관련 분류 | Xcode 개발 파일 | 제품 이름을 남기고 기호로 압축한 이름을 없애요. |
| 앱 사용 로그 | 앱 사용 기록 | 앱을 쓰면서 쌓이는 기록이에요. |
| 홈 디렉터리 | 내 폴더 | ‘내 사용자 폴더’보다 말하기 자연스러워요. 경로를 보여줄 때 ~는 유지해요. |
| 애플리케이션 | 앱 | 일반 설명에 써요. 실제 폴더 이름인 ‘응용 프로그램’은 그대로 둬요. |
| 가상 기기 | 가상 기기 | 개발 중인 앱을 실행해 보는 대상이라고 설명해요. 안의 앱, 설정, 데이터 삭제 여부는 별도로 알려줘요. |
| 메일 첨부 파일의 복사본 | 메일 첨부 사본 | 메일 원본과 구별해요. 원본이 남고 다시 열면 사본이 생긴다고 설명해요. |
| 내려받기 | 받기 | 문장에서는 ‘다시 받아요’를 써요. 짧고 정확한 기존 파일 분류는 억지로 바꾸지 않아요. |
| 휴지통으로 보내기 | 휴지통으로 옮겨요 | 즉시 영구 삭제와 구별해요. |
| 영구 삭제 | 완전히 지워요 | 복구할 수 없다는 사실을 함께 말해요. |
| 앱 안에서 원위치로 돌리기 | 복구 | 상태 표시는 ‘복구 중’, ‘복구 완료’로 통일해요. 행동을 설명할 때는 ‘되돌려 놓기’도 써요. |
| 안전 표시 | 안전, 주의, 위험 | 짧은 기존 이름을 유지해요. 칩에도 SAFE, REVIEW, DANGER 대신 이 말을 써요(영어 화면은 Safe, Caution, Danger). |
| 다시 만들 수 있는 묶음 | 다시 생김 | 좁은 칸에서는 짧게 쓰고 실제 재생성 조건은 각 항목에서 알려줘요. |

‘사라져요’와 ‘사라질 수 있어요’는 서로 바꿀 수 없어요. 정리할 파일의 용량과 휴지통을 비운 뒤 생기는 빈 공간도 서로 다른 말이에요.

## SweepApp 화면에서 쓰는 말

| 대상 | 쓰는 말 | 이유와 쓰임 |
|---|---|---|
| 정리 전 발견한 파일 | 정리 후보 | 아직 지워도 되는지 결정하지 않았어요. 바로 쓸 수 있는 빈 공간과 구분해요. |
| 완전히 지우는 짧은 버튼 | 완전 삭제 | 설명에서는 ‘완전히 지워요’라고 말하고 복구 불가를 함께 알려요. |
| CPU의 시스템 사용량 | 시스템 | macOS가 쓰는 몫이에요. ‘Mac 작동’이라는 어색한 이름을 바꿨어요. |
| CPU에서 쓰지 않는 몫 | 여유 | ‘쉬는 중’ 대신 남아 있는 여력을 나타내요. |
| 크기를 비교하는 막대 | 차지한 몫 | 좁은 표에서 공간 크기를 비교하는 칸이에요. |
| 원래 자리로 복구할 수 없는 상태 | 복구 불가 | 짧은 안전 안내에 써요. ‘다시 만들 수 없음’과 구분해요. |
