## 잰 것 (스크린샷 1344×698에서 픽셀로)

- 창 폭 대비 우측 독: 약 252/1180 ≈ 21%
- 목록 행 높이: 약 56pt (체크박스 위→아래 간격 기준)
- 섹션 헤더: 약 34pt, 배경이 행보다 어둡고 상단에 고정
- 체크박스 16pt, 안전도 아이콘 슬롯 11pt, 둘 사이 간격 약 14pt
- 선택된 행: 파란 틴트 배경 (accent 9%), 미선택은 투명

## 살릴 것

1. **하단 액션 바가 없다.** 선택 요약·안전도 분포·주 동작이 전부 우측 독에 모여 있다
2. **안전도가 색 알약이 아니라 작은 아이콘이다.** 안전=빈 원(무채색), 주의=삼각형(흙빛 주황),
   위험=자물쇠. 목록이 색으로 덮이지 않고 위험한 것만 눈에 든다
3. **묶음이 위치가 아니라 판단 기준이다.** "다시 받을 수 있음 / 원본 자료" —
   훑기만 해도 고를 수 있다
4. 상단에 기능별 설명 한 문장. "설치 파일은 다시 받을 수 있습니다…"
5. 미선택 행의 용량이 흐리다 (textTertiary). 선택하면 또렷해진다

## 버릴 것

- 초록/주황/빨강 배지 3종 (`SafetyBadge`)
- 하단 액션 바 (`actionBar`)
- 위험 항목의 좌측 3pt 경고 바 → 자물쇠 아이콘으로 대체

## 못 찾은 것

- 확인 시트·완료 화면은 프로토타입 아래쪽 섹션에 있으나 이번 캡처에서 못 봤다.
  README 8·9절의 확정 수치(폭 440, radius 12, padding 26 등)를 근거로 삼는다
- 투명 재질의 실제 흐림 정도 — HTML은 `backdrop-filter` 흉내이고
  네이티브는 `NSVisualEffectView` 실물이라 애초에 1:1 대응이 아니다
