# 개요 (스마트 스캔 결과)

- 출처: 같은 프로토타입, 첫 화면 (2026-09-16 직접 봄)

## 살릴 것

1. **도넛이 아니라 가로 스택 막대.** 조각이 3개고 비율이 1:1:0.01이라
   링에서는 중복이 실처럼 사라진다. 막대는 그 비율이 그대로 읽힌다
2. 히어로: 합계 큰 숫자 + "회수 가능" + 우측에 항목 수
3. 막대 아래 범례 3개 (작은 사각 + 캡션)
4. 기능 목록 카드: 색 점 → 이름+설명 → 용량(1위만 accentText) → chevron
5. 하단 주석으로 보호 항목 안내

## 버릴 것

- 기존 `DiskDonut`을 결과 화면에서 쓰는 것 (첫 실행의 사용/사용가능 2조각에는 남겨도 된다)

## 못 찾은 것

- 스택 막대 각 구간의 최소 폭 규칙. 중복 276MB가 전체의 0.5%인데 프로토타입에서는
  보이는 두께를 갖는다 — 최소 폭 하한이 있는 것으로 보이나 수치는 명시돼 있지 않다
