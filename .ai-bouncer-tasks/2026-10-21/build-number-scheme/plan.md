# 빌드 번호에 버전을 담는다: 1.0.5 → 10501, 10502 …

## Context
Mac 앱은 빌드 번호(`CFBundleVersion`)가 버전과 상관없이 계속 커져야 해요(Apple TN2420, 오늘 1.0.5 (1) 업로드가 오류 90061로 거부). 사용자는 "버전이 바뀌면 빌드가 1부터"인 느낌을 원해서, **버전을 빌드 번호 안에 넣는 규칙**으로 하기로 했어요. 끝 두 자리는 버전마다 01부터 시작하고, 숫자 전체는 항상 커져요.

## 규칙
```
빌드 = 주버전×10000 + 부버전×1000 + 패치×100 + 회차(01~99)
1.0.5 첫 빌드 = 10501, 두 번째 = 10502
1.0.6 첫 빌드 = 10601,  1.1.0 첫 빌드 = 11001,  2.0.0 첫 빌드 = 20001
```
- 부버전과 패치는 **0~9**까지만 쓴다. 1.0.9 다음은 1.0.10이 아니라 1.1.0이다(1.0.10은 11001이 돼 1.1.0과 겹친다).
- 회차는 01~99. 같은 버전을 다시 올릴 때만 +1.
- 지금 올라간 1.0.5 (11)은 그대로 둔다(이미 업로드됨, 심사에 문제 없음). 새 규칙은 다음 빌드부터. 1.0.5를 다시 올리게 되면 10501(11보다 커서 통과).

## 변경

### `scripts/make-archive.sh` — 버전 검사에 규칙 확인 추가
```bash
# 빌드 번호는 버전을 담는다: 주×10000 + 부×1000 + 패치×100 + 회차(01~99).
IFS=. read -r MAJ MIN PAT <<< "$VERSION"; MIN=${MIN:-0}; PAT=${PAT:-0}
[ "$MIN" -le 9 ] && [ "$PAT" -le 9 ] \
  || fail "버전 $VERSION — 부버전·패치는 0~9까지예요. 다음은 $MAJ.$((MIN+1)).0으로 올려요"
BASE=$(( MAJ*10000 + MIN*1000 + PAT*100 ))
if [[ "$BUILD" =~ ^[0-9]+$ ]] && [ "$BUILD" -gt "$BASE" ] && [ "$BUILD" -le $((BASE+99)) ]; then :
else fail "빌드 $BUILD — 버전 $VERSION의 빌드는 $((BASE+1))~$((BASE+99))여야 해요(첫 빌드 $((BASE+1)))"; fi
```
- 기존 "이전 업로드보다 커야 한다" 검사는 그대로 둔다. 둘 다 통과해야 아카이브한다.
- 예외: 이미 올라간 1.0.5 (11) 같은 옛 번호는 `ALLOW_LEGACY_BUILD=1`일 때만 통과시킨다(지금 main의 Info.plist가 1.0.5 (11)이라 CI가 이 검사에 막히면 안 된다 — 단, CI는 빌드 번호가 안 바뀌면 아카이브하지 않으니 실제로 걸릴 일은 없다. 그래도 `--check-only`를 손으로 돌릴 때 이유를 알게 메시지를 남긴다).

### `.claude/skills/sweep-release/SKILL.md` §3 버전
```
**빌드 번호는 묻지 않는다.** 버전을 빌드 번호에 담는다: 주×10000 + 부×1000 + 패치×100 + 회차.
- 버전을 올리면 회차 01: 1.0.5 → 10501, 1.1.0 → 11001
- 같은 버전을 다시 올리면 +1: 10501 → 10502
- 부버전·패치는 0~9. 1.0.9 다음은 1.1.0.
Mac 앱은 빌드 번호가 버전과 상관없이 계속 커져야 해서(TN2420, 오류 90061) 1로 돌릴 수 없다. 이 규칙은 숫자는 계속
커지면서 끝 두 자리는 버전마다 01부터 시작한다.
```

## 검증
- `PLIST=<임시> bash scripts/make-archive.sh --check-only`로 위 경우들을 돌려 통과·멈춤을 확인한다.
- 지금 main의 1.0.5 (11)에서 `--check-only`가 "옛 번호" 안내와 함께 멈추고, `ALLOW_LEGACY_BUILD=1`이면 통과하는지 확인한다.
- `release-diff.sh`는 바꾸지 않는다(빌드 번호가 바뀌면 업로드, 그대로).
- main에 바로 커밋·푸시한다(문서·스크립트만, 빌드 번호는 안 바꿔서 업로드가 일어나지 않는다).
