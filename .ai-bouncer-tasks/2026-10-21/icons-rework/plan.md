# 개발 프로젝트·공간 보기 아이콘 다시 그리기

## Context
PR #29에서 그린 아이콘이 마음에 들지 않아 다시 그리라는 요청이에요. 캡처에서 보면 이유가 보여요.
- **개발 프로젝트**: 새로 그린 게 아니라 기존 `.box`(금색 상자에 화살표 같은 무늬)를 가져다 썼어요. 무엇을 하는 기능인지 안 읽혀요. 정리 목록 줄의 분류 아이콘으로도 같은 `.box`를 쓰고 있어요.
- **공간 보기**: 청록 덩어리가 대부분이고 노랑·작은 블록이 한쪽에 몰려 있어 24pt에서 뭉개져요. 블록 지도라는 느낌이 약해요.

브랜치는 PR #29(`fix/safety-chip-copy-icons`) 위에서 이어서 커밋해요. 그림은 코덱스가 그리고 내가 렌더 결과를 눈으로 확인해요.

## 방향 (코덱스에게 줄 설계)
1. **개발 프로젝트 → 터미널 창** (`devProject`, 새 그림)
   - 남색 제목 줄이 있는 검은 창, 안에 초록 프롬프트 `>_`. 개발자가 한눈에 "코드 작업"으로 읽는 그림이에요.
   - 기존 `.box`는 그대로 두고(정리 목록의 분류 아이콘), 새 그림은 사이드바와 개발 프로젝트 화면의 그림에만 써요.
2. **공간 보기 → 블록 지도** (`spaceView` 다시 그리기)
   - 한 판을 크기가 다른 색 블록 네 개로 나눠요: 큰 블록 하나(청록), 오른쪽 위(노랑), 오른쪽 아래 둘(빨강, 초록). 블록 사이는 1칸 검정 선, 바깥도 검정 외곽선이에요. 흰 여백이나 하이라이트 줄로 면을 먹지 않아요.
   - 색이 서로 달라야 "크기를 비교하는 지도"로 읽혀요.
