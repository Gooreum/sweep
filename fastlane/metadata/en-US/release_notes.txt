See what is slowing your Mac down, and every message is easier to understand.

• CPU tab — See which programs keep your Mac busy, using the same numbers as Activity Monitor.
• Program details — Click a program to see what it is, who started it, how long it has been running, its memory and the command it was started with.

• New menu names — Smart Scan is now “Search All”, Junk Files is “Files to Clean” and Disk Map is “Space View”.
