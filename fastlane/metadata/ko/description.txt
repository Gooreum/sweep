[코드는 쌓이고, 저장공간은 줄어듭니다]

어느새 수십 GB를 차지한 Xcode 빌드 파일, 사용하지 않는 시뮬레이터, 다운로드 폴더에 쌓인 설치 파일들.

개발하다 보면 Mac 저장공간은 생각보다 빠르게 사라집니다.

Sweep은 이렇게 쌓인 파일을 찾아내고, 무엇을 지워도 되는지 판단할 수 있도록 도와주는 Mac 전용 디스크 정리 앱입니다.

[찾는 건 빠르게. 지우는 건 신중하게]

■ 개발자의 Mac을 위한 '한번에 찾기'

여러 곳에 흩어진 불필요한 파일을 한 번에 찾아보세요.

• Xcode DerivedData와 빌드 캐시
• iOS 시뮬레이터 및 기기 지원 파일
• npm, Yarn, pnpm, Expo 등 개발 도구 캐시
• Swift Package Manager, CocoaPods, Homebrew 관련 캐시
• 다운로드 폴더의 대용량 파일
• 내용이 동일한 중복 파일

찾은 파일은 '정리할 파일', '큰 파일', '중복 파일'로 나뉘어 보이고, 정리할 수 있는 용량을 한눈에 확인할 수 있습니다.

■ 지워도 괜찮을까? Sweep이 구분해 드립니다.

디스크 정리에서 가장 중요한 건 얼마나 많이 지우느냐가 아니라, 무엇을 지우느냐입니다.

Sweep은 파일의 특성에 따라 안전도를 세 단계로 구분합니다.

• 안전(SAFE) — 삭제해도 다시 생성할 수 있는 파일
• 주의(REVIEW) — 다시 다운로드하거나 확인이 필요한 파일
• 위험(DANGER) — 삭제하면 복구하기 어려운 파일

기본적으로 안전한 항목만 선택됩니다. 중요한 Xcode Archives나 개발 환경 설정을 무심코 삭제하지 않도록 설계했습니다.

■ '큰 파일'로 다운로드 폴더 속 큰 파일 찾기

100MB 이상의 큰 파일을 크기순으로 확인하세요.

예전에 설치했던 DMG 파일, 한 번 보고 잊어버린 영상, 오래된 압축 파일까지.

다운로드 시점도 함께 확인하고, 더 이상 필요 없는 파일만 골라 정리할 수 있습니다.

■ '중복 파일'로 똑같은 파일은 한 벌만

파일 이름이 달라도 내용이 같다면 중복 파일로 찾아냅니다.

파일 내용을 비교해 동일한 파일을 식별하고, 가장 먼저 받은 원본은 정리 대상에서 제외합니다.

■ '공간 보기'로 공간 사용량을 한눈에

어떤 폴더가 저장공간을 가장 많이 차지하고 있을까요?

파일과 폴더의 크기를 시각적으로 비교하고, 폴더 내부를 탐색해 보세요.

Finder에서 보기, 위치 복사, 휴지통으로 옮기기까지 바로 실행할 수 있습니다.

■ 'CPU'로 Mac이 왜 느린지 확인

지금 컴퓨터를 바쁘게 하는 프로그램을 사용률 순서로 보여줍니다. 활성 상태 보기와 같은 기준의 숫자입니다.

프로그램을 누르면 무엇인지, 누가 켰는지, 얼마나 오래 켜져 있는지, 메모리와 실행한 명령, 파일 위치를 쉬운 말로 알려줍니다. 끄지 말아야 하는 macOS 기본 프로그램도 구분해 줍니다.

App Store 버전은 보안 정책상 macOS 시스템이 직접 켠 일부 프로그램은 개별로 볼 수 없고, 합계로 보여줍니다.

■ 실수로 지웠다면? 되돌리세요.

Sweep은 정리한 파일을 즉시 영구 삭제하지 않습니다.

• 삭제한 파일은 먼저 macOS 휴지통으로 이동
• 마지막 정리 작업은 '복구'로 되돌리기 가능
• 휴지통을 비워야 실제 저장공간이 확보된다는 점을 명확하게 안내
• 정해진 정리 범위 밖의 파일은 건드리지 않음

정리할 파일은 직접 선택하고, 삭제 전에 다시 확인할 수 있습니다.

■ 1995년의 감성, 지금의 Mac에서

회색 패널, 픽셀 아이콘, 입체적인 버튼.

Sweep은 90년대 데스크톱 유틸리티에서 영감을 받은 레트로 인터페이스를 제공합니다.

익숙한 파일 목록과 촘촘한 정보 배치로 필요한 내용을 빠르게 확인하세요.

■ 작업 흐름을 방해하지 않도록

• 메뉴 막대에서 디스크 상태와 정리 가능한 용량 확인
• 앱 창을 열지 않고 스캔 시작
• ⌘R로 스캔, ⌘⌫로 정리
• 목록의 열 너비를 원하는 대로 조절

■ 내 파일은 내 Mac에만

Sweep은 인터넷 연결 없이 작동합니다.

파일 목록과 내용은 외부 서버로 전송되지 않으며, 개인정보나 사용 데이터를 수집하지 않습니다.

App Store 버전은 macOS의 보안 정책에 따라 일부 개발 폴더에 대한 접근 권한이 필요합니다. 접근 권한은 사용자가 직접 허용하고 관리할 수 있습니다.
