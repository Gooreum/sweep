개발자용 새 탭과 알림이 생기고, 안내가 더 쉬워졌어요.

• 개발 프로젝트 탭 — 코드 폴더를 알려 주면 node_modules, .venv, Pods처럼 지워도 다시 만들어지는 폴더를 크기순으로 보여줘요.
• 디스크 부족 알림 — 남은 공간이 정한 값보다 적어지면 메뉴 막대에서 알려줘요. 설정에서 켜고 끌 수 있어요.
• 더 쉬워진 설명 — 정리 목록, CPU 탭, 확인창의 설명을 모르는 말 없이 다시 썼고, 안전 표시도 한글로 바꿨어요.
• 새 아이콘 — CPU, 공간 보기, 개발 프로젝트 아이콘이 기능을 한눈에 알려줘요.
• 고친 것 — 정리한 파일을 되돌리면 다른 탭에도 돌아와요. 큰 파일과 중복 파일도 이제 되돌릴 수 있어요.
